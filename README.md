# TargetSistemas
Desafio técnico para a vaga de Desenvolvedor Jr na Target Sistemas.

Aqui tem a resolução dos 3 desafios que me mandaram.

- **Desafio 1**: Cálculo das comissões de venda lendo os dados de um json.
- **Desafio 2**: Controle de estoque bem simples que roda no console e atualiza um json.
- **Desafio 3**: Script pra calcular o juros de uma fatura com base nos dias de atraso.

Foi feito em C#. É só entrar na pasta de cada desafio pelo terminal e dar um `dotnet run` pra testar.
